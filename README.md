# Chocotto-Select-Hub

チョイセレ（Choisere）の**公式ハブ/LP（静的サイト）**用リポジトリです。  
GitHub Pagesで公開し、`main`へpushすると内容が更新されます。

## どこを編集すればいい？

- **LP本体**: `index.html`
- **画像など**: `assets/`

## GitHub Pages（GUI設定）

1. GitHubでこのリポを開く
2. `Settings` → `Pages`
3. `Build and deployment`
   - `Source`: **Deploy from a branch**
   - `Branch`: **main**
   - `Folder`: **/(root)**
4. `Save`
5. 表示されたら `Enforce HTTPS` をON

公開URLは、Pages画面の `Your site is live at ...` に表示されます。

## ルール（重要）

- **機密は絶対に置かない**（APIキー/トークン/秘密鍵/顧客情報/管理画面URLなど）
